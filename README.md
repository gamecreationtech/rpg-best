# Falling Sky

Falling Sky is a new role-playing game currently in early development.

## Status

Pre-production. No engine or build pipeline has been committed yet. This repository
currently holds project documentation and conventions only.

## Repository layout

| Path | Purpose |
| --- | --- |
| `docs/design/` | Game design documents (world, systems, story, art direction) |
| `CLAUDE.md` | Conventions for contributors and AI-assisted development |

Engine-specific folders (source, assets, scenes) will be added once the engine is chosen.

## Getting started

There is nothing to build or run yet. Start with the
[game design document](docs/design/game-design-document.md).

## Contributing

- Work on a feature branch and open a pull request against `main`.
- Keep design decisions in `docs/design/` so the reasoning survives beyond chat and issues.
- Large binary assets should go through Git LFS once it is set up.
